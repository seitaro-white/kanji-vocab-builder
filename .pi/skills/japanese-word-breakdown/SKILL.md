## Output sections

Produce an output with this outline

1. **Headword line** — **word** [reading] (POS) "core meaning"
2. **Senses & patterns** — each meaning on its own line, carrying the grammatical pattern that realizes it.
3. **Example sentences** — a set of example sentences using N5-N2 language that demonstrate how the vocab is used in natural language (accompanied with English translation)
4. **Why those kanji** — *word level only*: what each character contributes to the meaning (上 = up/high + 等 = class → 上等 "high class").
